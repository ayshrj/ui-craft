# Contributing

Use a branch and pull request. Preserve substantive guidance, distinguish heuristics from standards, cite authoritative sources when introducing new claims, and add concrete acceptance criteria. Keep skill instructions concise and references self-contained.

The original root playbook is preserved as source. When intentionally updating it, update the bundled reference in the same change. Run `python3 scripts/validate-skills.py` before opening a PR. Do not include credentials or private customer data.
